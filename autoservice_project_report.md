# Отчет по проекту
# Информационная система автосервиса и склада запчастей

---

# 1. Описание проекта

## Тема проекта

Разработка информационной системы для автоматизации деятельности автосервиса и склада автомобильных запчастей.

Система предназначена для:

- регистрации клиентов;
- учета автомобилей;
- создания заказ-нарядов;
- учета сотрудников;
- хранения информации о выполняемых работах;
- учета и списания запчастей;
- управления складом.

---

# 7. Схема данных (IDEF1X / ERD)

## Сущности базы данных

### 1. Users

Хранит информацию о клиентах.

Поля:

- id
- fullname
- phone
- email
- password

---

### 2. Cars

Хранит автомобили клиентов.

Поля:

- id
- brand
- model
- year
- vin
- user_id

Связь:

- один пользователь → много автомобилей.

---

### 3. Employees

Хранит сотрудников автосервиса.

Поля:

- id
- fullname
- position
- phone

---

### 4. Services

Справочник услуг.

Поля:

- id
- name
- price

---

### 5. Parts

Справочник запчастей.

Поля:

- id
- name
- sku
- price
- stock

---

### 6. Orders

Заказ-наряды.

Поля:

- id
- car_id
- employee_id
- status
- created_at

Связи:

- один автомобиль → много заказов;
- один сотрудник → много заказов.

---

### 7. OrderServices

Связующая таблица заказов и услуг.

Поля:

- id
- order_id
- service_id
- quantity

---

### 8. OrderParts

Связующая таблица заказов и запчастей.

Поля:

- id
- order_id
- part_id
- quantity

# 9. SQL запросы

## 1. Список клиентов

```sql
SELECT * FROM users;
```

---

## 2. Список автомобилей клиента

```sql
SELECT * FROM cars
WHERE user_id = 1;
```

---

## 3. Все заказы

```sql
SELECT * FROM orders;
```

---

## 4. Заказы с клиентами и автомобилями

```sql
SELECT
    orders.id,
    users.fullname,
    cars.brand,
    cars.model,
    orders.status
FROM orders
JOIN cars ON orders.car_id = cars.id
JOIN users ON cars.user_id = users.id;
```

---

## 5. Подсчет стоимости услуг

```sql
SELECT
    services.name,
    services.price * order_services.quantity AS total_price
FROM order_services
JOIN services ON services.id = order_services.service_id;
```

---

## 6. Запчасти с малым остатком

```sql
SELECT * FROM parts
WHERE stock < 5;
```

---

## 7. Количество заказов у сотрудников

```sql
SELECT
    employees.fullname,
    COUNT(orders.id) AS orders_count
FROM employees
LEFT JOIN orders ON employees.id = orders.employee_id
GROUP BY employees.fullname;
```
