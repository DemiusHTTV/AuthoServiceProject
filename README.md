# AutoService Project

Учебный проект сети автосервисов с веб-интерфейсом, основным FastAPI-бэкендом, отдельным складским сервисом и общей библиотекой доменной логики.

## Структура проекта
- `frontend/` — статический фронтенд на HTML/CSS/Vanilla JS и конфиг Nginx
- `app/` — основной FastAPI-сервис: клиенты, заявки, админ-панель, рабочие места сотрудников
- `warehouse_service/` — отдельный FastAPI-сервис склада
- `lib/autoservice_core/` — общая библиотека расчёта и доменных моделей
- `data/` — CSV-файлы начального наполнения
- `docs/` — техническая документация по проекту
- `test/` — автотесты и экспериментальные проверки

## Быстрый запуск через Docker
```bash
docker-compose up --build
```

После старта будут доступны:
- `http://localhost/` — клиентский интерфейс
- `http://localhost/admin` — панель администратора
- `http://localhost/worker` — панель сотрудника
- `http://localhost:8000/docs` — OpenAPI основного сервиса
- `http://localhost:8001/docs` — OpenAPI складского сервиса

В клиентском интерфейсе авторизованный пользователь может:
- создавать заявки
- видеть бонусный баланс
- списывать бонусы при оформлении заявки в пределах стоимости выбранной услуги

## Локальный запуск без Docker
Основной сервис:
```bash
uv run uvicorn app.main:app --reload
```

Складской сервис:
```bash
uv run uvicorn warehouse_service.main:app --reload --port 8001
```
