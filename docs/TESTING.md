# Стратегия тестирования

Проект покрыт двумя видами автотестов:

1. **Unit-тесты (Модульные)**
   - Проверяют изолированную логику расчета цены (библиотека `autoservice_core`).
   - Находятся в `test/unit/`.

2. **Smoke-тесты (Интеграционные)**
   - Запускают FastAPI приложения через `TestClient`.
   - Проверяют доступность healthcheck-эндпоинтов бэкенда и склада.
   - Находятся в `test/smoke/`.

## Запуск тестов
Тесты запускаются через пакетный менеджер `uv` с использованием `pytest`:

```bash
uv run python -m pytest test/
```
