# Основной сервис `app/`

## Назначение
Сервис отвечает за:
- регистрацию и авторизацию клиентов
- приём и просмотр заявок
- бонусную механику клиента при создании заявки
- админскую панель
- рабочее место сотрудника
- выдачу списка услуг
- проксирование складских данных в UI

## Запуск
Локально:
```bash
uv run uvicorn app.main:app --reload
```

Через Docker:
```bash
docker-compose up backend
```

Сервис доступен на `8000` порту.

## Технологии
- `FastAPI`
- встроенный `sqlite3` вместо ORM
- `httpx` для обращения к складу
- `uv` для запуска и workspace-зависимостей

## Структура
- `app/main.py` — создание приложения, подключение роутеров, раздача фронтенда
- `app/routers/clients.py` — клиенты и личный кабинет
- `app/routers/requests.py` — заявки
- `app/routers/admin.py` — функции администратора
- `app/routers/workers.py` — функции сотрудников
- `app/routers/warehouse.py` — прокси к складскому сервису
- `app/database.py` — инициализация SQLite и загрузка данных из CSV
- `app/config.py` — базовые пути и переменные окружения

## База данных
- файл БД: `autoservice.db` в корне проекта
- начальные данные берутся из `data/*.csv`
- таблицы создаются на старте приложения через `init_db()`
- сиды загружаются через `seed_db()`
- в заявке сохраняются `estimated_price`, `bonus_spent`, `final_price`
- история бонусов клиентов хранится в таблице `bonuses`
- бонусы сотрудников по выполненным задачам хранятся в `worker_bonuses`

## Основные маршруты
- `/api/clients/*`
- `/api/requests/*`
- `/api/admin/*`
- `/api/workers/*`
- `/api/warehouse/*`
- `GET /api/services`

## Особенности реализации
- фронтенд может обслуживаться самим FastAPI через `FileResponse` и `StaticFiles`
- адрес склада задаётся через `WAREHOUSE_URL`
- общая доменная логика вынесена в `lib/autoservice_core`
- при создании заявки авторизованный клиент может списать бонусы в пределах своего баланса и базовой цены услуги
