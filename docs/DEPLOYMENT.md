# Инструкция по развертыванию (Deployment)

## Требования
- Docker
- Docker Compose
- Установленный `uv` (для локальной разработки без Docker)

## Развертывание в Production
1. Склонируйте репозиторий на боевой сервер.
2. Выполните сборку образов:
   ```bash
   docker-compose build
   ```
3. Запустите сервисы в фоновом режиме:
   ```bash
   docker-compose up -d
   ```

## Переменные окружения
В Production рекомендуется вынести переменные из хардкода в `.env` файл:
- `WAREHOUSE_URL` — адрес микросервиса склада (сейчас: `http://warehouse:8001`).
- `DATABASE_URL` — строка подключения (если решите мигрировать с SQLite на PostgreSQL).

## Резервное копирование
Бэкап баз данных сводится к копированию папок:
- `app/data/`
- `warehouse/app/data/`
