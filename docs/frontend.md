# Техническое описание: Фронтенд

## Запуск
```bash
docker-compose up frontend
```
Запускает Nginx на порту 80, раздающий статические файлы из папки `frontend/`.

## Архитектура
Фронтенд реализован на **Vanilla JS, HTML, CSS** (без использования фреймворков типа React или Vue), чтобы минимизировать зависимости и показать работу с чистым DOM API.

## Основные скрипты (`js/`)
1. **`main.js`** — Логика главной страницы:
   - Взаимодействие с `/api/users/login` и `/api/users/register` (Авторизация).
   - Загрузка услуг из `/api/services/`.
   - Отправка заявок через `/api/orders/public`.
2. **`admin.js`** — Панель администратора.
3. **`worker.js`** — Панель автомеханика.
